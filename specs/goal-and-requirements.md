# Aura Tab — 产品目标与范围

## Goal

把 Chrome / Edge 的新标签页变成一页可定制的桌面：一张壁纸，一个时钟，一个搜索框，一排常用入口。

新标签页是打开频率最高的页面，浏览器自带的那一页只有搜索框。Aura Tab 取代它，让这一页承载桌面级的日常入口——壁纸轮换、快速链接、Dock、启动台——同时保持打开瞬间就能用。

面向：日常在桌面浏览器里工作、习惯 macOS 观感的中英双语用户。UI 必须中英双语可用（简体、繁体、英文）。

## Capabilities

- **壁纸**：来源为本地文件、Unsplash、Pixabay、Pexels、Bing 五种；可设轮换间隔（每次开新标签 / 每小时 / 每天 / 不轮换）；按屏幕尺寸自动裁剪（含焦点检测），压缩后缓存复用；可调模糊、亮度、遮罩、纹理。
- **页面外壳**：时钟与日期（12/24 小时、可选秒、中英日期格式）、搜索框（可切换搜索引擎、可选新标签打开；候选是一列：命中的快速链接打头、然后是可选引擎联想词——默认开启，来源固定 Bing，输入会随打字发送给它——最后是本机历史；按标题、标签和网址搜，多个词同时命中才算）、可配快捷键（聚焦搜索、打开启动台）、明暗主题。
- **快速链接**：分页网格，条目可放进文件夹，支持拖拽排序、即时搜索、自定义图标外观；可固定到屏幕顶部或底部的 Dock（带放大效果）；启动台是全屏应用启动器，支持文件夹、分页、拖拽合并。
- **书签**：从 Chrome 书签一键导入（自动去重、分页），以及导出。
- **照片查看器**：以壁纸库为来源的全屏浏览，键盘导航，收藏。
- **设置**：独立窗口，分区为通用 / 外观 / Dock / 数据 / 关于 / 更新日志。
- **数据**：整库导出与导入（zip），以及通过用户自己的 WebDAV（坚果云、群晖等）备份与恢复。
- **更新日志**：扩展升级后展示新版本的改动。
- **国际化**：简体中文、繁体中文、英文三套文案，跟随浏览器语言或手动指定。

## Non-goals

- 不做自己的账号体系或云服务；备份只走用户自己的 WebDAV。桌面靠 `chrome.storage.sync` 在用户自己的浏览器之间同步。
- 不做移动端形态，也不做独立桌面 App；产品只有一个形态：浏览器扩展。

未列在这里的东西不代表要做——没被排除的就是还没决定。

## Principles

- **不收集数据。** 没有分析、埋点、自有服务端；壁纸来自第三方图库的公开接口，用用户自己的 API Key。唯一把用户输入交给第三方的是搜索联想：逐字发给 Bing，默认开启，第一次打开候选面板时说明一次并给出关闭入口。
- **打开即可用。** 新标签页每次打开都要重新加载，首屏不能等网络或 JS 初始化：首屏颜色/预览在模块脚本执行前就已画上，其余功能在空闲时挂载。
- **数据待在浏览器里。** 全部状态在扩展自己的存储里，不依赖后端；换设备靠 sync 与手动备份。
