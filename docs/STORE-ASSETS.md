## 二、仓库里现有素材必须全部重做

这些是上游产品的素材，不能复用：

- **`assets/icons/` 三个文件是同一个 1254×1254 的图**（md5 完全相同），每个 1.07 MB，合计 3.14 MB 都打在安装包里。也就是说 `manifest.json` 声明的 16/48/128 实际全都不成立。必须分别导出真尺寸。
- `assets/other/` 6 张（38 MB）是上游产品的截图，3572×1932，Dock、启动台、设置窗口里都还写着 Aura Tab。上架前必须重拍。
- `docs/images/` 同样来自上游（31 MB），落地页要跟着换。

## 三、图标设计：16px 决定一切

品牌意象来自荔枝的构造：**外壳 → 薄衣 → 半透明果肉 → 中心一颗核**。对应到界面就是外壳轮廓、半透明图层、`backdrop-filter` 毛玻璃、居中的时钟与搜索框。

三档尺寸不是同形缩放，而是逐级减细节：

- **128px**：可以画剖面——外壳弧线 + 半透明果肉 + 中心一颗核。
- **48px**：剖面的层次会糊掉，退化成「一圈弧 + 一个点」。
- **16px**：只保留一个可辨识单形。最稳的做法是**只画核**——一个小圆，外面一圈弧。不要在 16px 里放字母 L，会糊成一团。

具体要求：

- 从 1024×1024 起稿，导出 128/48/16 三档，不要直接缩放（16px 需要手动调像素）。
- 主体距画布边缘留 8–10%，商店卡片会裁圆角，贴边会被切。
- 颜色：外壳取偏红的深阶；果肉用半透明白；核用界面里现有的光晕色，一眼能对上产品。
- 16px 下不要有细描边（< 1.5px 会消失），不要渐变噪点。
- 自检方法：把成品缩到 16px 铺在深色和浅色两种背景上各看一眼，认得出才算过。

## 四、截图

硬要求：

- 1280×800 或 640×480，两张里选一种，全部统一，不要混用。
- 不要圆角、不要设备外框、不要超出画布的阴影。
- 1–6 张。**第一张最重要**，它决定点击率。
- 每个语言单独一套：`en` 和 `zh_CN` 必须有，`zh_TW` 可选。

建议顺序与内容：

1. **整页**：壁纸 + Dock + 时钟。让人一眼明白这是新标签页。
2. **快速链接与文件夹**：展示管理能力，不是只换个壁纸。
3. **启动台**：这是区别于普通新标签页的差异点。
4. **设置窗口**：证明可配置、可关。
5. **照片查看器**：第二个差异点。
6. **搜索聚合面板**：1.0 的亮点。

禁止项（审核会看，也确实影响观感）：

- 不出现任何第三方品牌 logo：书签栏里的公司标志、其他扩展图标、系统设置图标。
- 不出现真实个人信息：书签里的私人网站、邮箱、头像、真实姓名。
- 不出现开发者工具、浏览器弹窗、系统通知。
- 壁纸若用第三方照片，确认可商用；最保险是自拍或纯色、渐变。
- 不要拼贴多张界面，不要加营销大标题，会显得像广告素材。

## 五、促销图

- **440×280**：logo + 一句话。留白要多，文字高度不低于 20px，否则小图里读不出。
- **1400×560**：界面 + 一句主张。不要把截图整张塞进去缩到看不清，取局部。

## 六、文字与语言

扩展里的名字已经改好，由 `_locales` 决定：`en` = Leechee，`zh_CN` / `zh_TW` = 荔枝。商店里的显示名会读这个值，不用另外起名。

商店描述是另外填的，250–10000 字符，每个语言一份。名字建议保持短——品类词（新标签页、壁纸、Dock、启动台）放进 search terms 字段，不要塞进名字，避免被审核认为标题过于营销。

## 七、放置位置

- 进包的三张：`assets/icons/icon{16,48,128}.png`，覆盖现有同名文件即可。
- 商店素材放 `assets/store/`。`package_extension.sh` 用的是白名单，只打包 `assets/backgrounds`、`assets/icons`、`assets/changelog.json`，所以 `assets/store/` 不会被打进安装包。
- 落地页素材放 `docs/images/`。
- 仓库里只放导出的 PNG；原始工程文件（AI / Figma / PSD）留在本地，不要提交。
